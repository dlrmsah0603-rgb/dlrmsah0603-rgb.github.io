# 문제 설명
가로 길이가 2이고 세로의 길이가 1인 직사각형 모양의 타일이 있습니다. 이 직사각형 타일을 이용하여 세로의 길이가 3이고 가로의 길이가 n인 바닥을 가득 채우려고 합니다. 타일을 채울 때는 다음과 같이 2가지 방법이 있습니다

타일을 가로로 배치 하는 경우

타일을 세로로 배치 하는 경우

예를들어서 n이 8인 직사각형은 다음과 같이 채울 수 있습니다.

직사각형의 가로의 길이 n이 매개변수로 주어질 때, 이 직사각형을 채우는 방법의 수를 return 하는 solution 함수를 완성해주세요.

> ### 제한사항
> 가로의 길이 n은 5,000이하의 자연수 입니다.
> 경우의 수가 많아 질 수 있으므로, 경우의 수를 1,000,000,007으로 나눈 나머지를 return해주세요.
<br>

# code
```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int solution(int n) {
    if (n % 2 == 1)
        return 0;
    if (n == 2)
        return 3;
    
    int answer;
    
    long long dp[2501];
    
    dp[0] = 1;
    dp[1] = 3;
    for (int i = 2; i <= 2500; i++){ //점화식에 따라 n까지 반복해 더한다.
        dp[i] = (4 * dp[i-1] - dp[i-2]) % 1000000007;
        if (dp[i] < 0)
            dp[i] += 1000000007;
        
        if (i * 2 == n){
            answer = dp[i];
            break;
        }
    }
    
    return answer;
}
```
<br>

# 해설

1. n을 짝수일 때만 0이 아닌 값을 갖습니다. 예외처리해줍니다.
2. 점화식을 만들기 위해 n == 0, n == 2일때의 값을 구합니다. (1, 3)
3. 점화식을 구합니다.

> 1. n크기 도형을 이룰 수 있는 경우의 수를 구합니다. 
> 2. n-2 크기 도형에 2 크기의 도형(3가지)이 붙을 수 있습니다.<br>-> 3*f*(n-2)
> 3. 어떤 크기 x의 상자는 왼쪽에 n-x 크기의 상자가 붙어 n 크기의 상자가 됩니다.<br>-> 2*f*(n-4)+2*f*(n-6)+...+2*f*(2)+2
> -> *f*(n)=3*f*(n-2)+2*f*(n-4)+2*f*(n-6)+...+2*f*(2)+2
>   -> *f*(n-2) = 3*f*(n-4) + 2*f*(n-6)+...+2*f*(2)+2 이므로<br>
>        *f*(n) = 4*f*(n-2)-*f*(n-4)

4. 위의 점화식을 4부터 n까지 반복해 n일 때의 값을 얻습니다.
